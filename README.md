# AI Workmate: Knowledge Legacy

**AI Workmate: Knowledge Legacy** is a working prototype of an AI-assisted tacit knowledge analysis and organizational knowledge chat system.

The system uses **Google Apps Script**, **Google Sheets**, and **Gemini API** to transform staff-written experiences into structured organizational knowledge and support AI-based knowledge retrieval through **AI Workmate Knowledge Chat**.

---

## Project Purpose

Organizations often risk losing valuable tacit knowledge when experienced staff retire, transfer, or move to other roles. Much of this knowledge is not written in official manuals, but exists in the form of experience, practical judgment, hidden techniques, problem-solving patterns, and lessons learned from real work.

This project aims to preserve and transfer that knowledge by using AI to extract insights from staff-written documents and convert them into structured knowledge assets for future use.

---

## Key Features

- Knowledge intake from staff-written text
- AI-powered tacit knowledge analysis using Gemini API
- Automatic knowledge categorization
- Extraction of key insights, hidden techniques, risks, solutions, and lessons learned
- Automatic Knowledge Card generation
- AI Workmate Knowledge Chat for asking questions from the extracted knowledge base
- Google Sheets as a lightweight knowledge database
- Google Apps Script Web App as the user interface

AI_ANALYSIS
KNOWLEDGE_CARD

Main fields include:

position
expertise_area
interview_question
raw_answer
status
created_at
source_type
document_title
consent_status
notes

Stores the results generated by Gemini AI after analyzing the raw knowledge.

Main fields include:

solution_pattern
risk_warning
step_by_step

Stores structured knowledge cards generated from AI analysis results.

created_at
Main Modules
1. Knowledge Intake

Collects staff-written documents, reflections, or interview transcripts. These inputs become the raw knowledge source for AI analysis.

2. AI Analysis

Uses Gemini API to analyze unstructured staff-written text and extract tacit knowledge elements such as:

Knowledge category
Key insight
Hidden technique
Common problem
Solution pattern
Risk warning
Step-by-step practice
Advice for new staff
Keywords
3. Knowledge Cards

Transforms AI analysis results into structured Knowledge Cards that can be reviewed, approved, reused, and transferred within the organization.

4. AI Workmate Knowledge Chat

Allows users to ask questions based on the Knowledge Cards stored in the system. The chat is designed to answer from the extracted organizational knowledge rather than general AI knowledge.

Security Note

The Gemini API key is not stored in this repository.

The API key should be configured securely in Google Apps Script using:

Project Settings → Script Properties → GEMINI_API_KEY

Do not hard-code API keys or sensitive credentials in any file uploaded to GitHub.
